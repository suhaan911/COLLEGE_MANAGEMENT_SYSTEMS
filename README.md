# College Management System

A sleek, responsive, and full-stack enterprise web dashboard designed to manage college relational entities efficiently. Built using an architectural dynamic CRUD engine, this application features a data-dense, compact UI that handles everything seamlessly without bulky interface clutter.

## 🚀 Features

* **Compact & Organized UI:** A crisp, high-density dashboard optimized for clean data visibility and lightning-fast navigation.
* **Dynamic CRUD Engine:** Fully automated creation and editing mapping layouts that adapt instantly based on the selected relational schema.
* **Comprehensive Entity Mapping:** Manages key database nodes: Students, Departments, Faculty, Courses, Classes, Exams, and Attendance tracking.
* **Relational Integrity Constraints:** Enforces clear index mappings (Foreign Keys) to connect students with classes, courses, and schedules.
* **Zero-Configuration Database:** Built on an in-memory SQLite core that automatically creates and seeds tables with clean mock datasets on launch.
* **Mock Authentication:** Secured control panel accessible via protected gatekeeper administration credentials.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Modern Glassmorphism & Tight Flexbox Grid), JavaScript (ES6+ Fetch API), FontAwesome Icons.
* **Backend:** Node.js, Express.js REST API Architecture.
* **Database:** SQLite3 (`sqlite3` in-memory module).
